# CIC-IDS-2017 dataset

The **CIC-IDS-2017** dataset provides a comprehensive set of benign traffic and the most prevalent common attacks. It is designed to resemble real-world network data through high-fidelity packet captures (PCAPs) and labeled flow analysis.

---

## Dataset Characteristics
This dataset captures a diverse range of network behaviors, providing two primary formats:

* **Raw Traffic (PCAP):** Full packet captures representing true real-world network traces.
* **Analyzed Flows (CSV):** Processed data generated via **CICFlowMeter**. These flows are labeled based on:
    * Timestamp
    * Source & Destination IPs
    * Source & Destination Ports
    * Protocols
    * Attack Classification (Label)


The dataset includes modern attack scenarios, including :
* **DoS/DDoS**
* **Brute Force**
* **Web Attacks**
* **Infiltration**
* **Heartbleed**
* **Botnets**
