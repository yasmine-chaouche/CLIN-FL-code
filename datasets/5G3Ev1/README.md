# 5G3E (5G End-to-End Emulation) Dataset — v1

The **5G3E Dataset** provides high-fidelity monitoring metrics from a virtualized 5G infrastructure. It is designed to support research in network automation, protocol design, and machine learning for 5G/6G systems.

---

## 📊 Overview
This dataset was generated by injecting **14 days of anonymized commercial cellular traffic** into an emulated 5G platform. The environment includes:
* **Emulated Radio Access Network (RAN)**
* **5G Core Network (5GC)**
* **Virtualized Infrastructure**

### Potential Use Cases
* Developing novel network automation architectures.
* Training AI/ML models for resource orchestration.
* Analyzing performance metrics across 5G protocols and algorithms.

---

## 📂 Dataset Description
The dataset consists of **thousands of time-series system metrics** collected at various sampling rates. These metrics provide a holistic view of the 5G ecosystem:

* **Radio Resources:** Radio front-end and signal metrics.
* **Computing Resources:** Physical server performance and Operating System (OS) telemetry.
* **Network Functions:** VNF/CNF specific metrics and throughput data.
